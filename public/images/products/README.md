## Image Specifications

- **Format**: JPG or PNG
- **Recommended Size**: 800x800px or larger (square format works best)
- **Aspect Ratio**: 1:1 (square) is recommended for consistency
- **File Size**: Optimize images to keep file sizes reasonable (under 500KB each)

## Tips

- Use high-quality images with good lighting
- Ensure the background matches your website aesthetic (light grey/white works well)
- Keep product images consistent in style and presentation
- Consider using image optimization tools before uploading
